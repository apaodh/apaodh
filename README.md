# 📺 TV Box 多线路聚合订阅

[![GitHub stars](https://img.shields.io/badge/dynamic/json?logo=github&label=Stars&query=%24.stargazers_count&url=https%3A%2F%2Fapi.github.com%2Frepos%2F%3CUSERNAME%3E%2F%3CREPO%3E)](https://github.com/apaodh/apaodh/backups)


> 🚀 本仓库聚合了多条主流 TV Box 线路的代理镜像，每日自动同步更新，解决部分地区无法直连 GitHub 导致线路失效的问题。

---

## ✨ 项目简介

由于国内访问 GitHub 受限，部分 TV Box 软件无法直接拉取原始配置文件。本项目通过 **gh-proxy** 代理，将常用的优质线路（肥猫、饭太硬、摸鱼等）进行聚合封装，方便一键导入。

**主要特点：**
- 🔄 **高速代理**：使用国内可访问的代理前缀，提高加载速度。
- 📋 **线路齐全**：囊括了市面上最受欢迎的 8 条影视源接口。
- 🏷️ **分类清晰**：每条线路均配备趣味图标，易于识别和选择。
- 📦 **多仓支持**：提供单一聚合地址，一次添加即可拥有全部线路（详见下文）。
